# 🐍 analysis-python

Servicio de análisis en Python (FastAPI) para AudioCheck: estadísticas y reportes **orientativos** de los resultados.

**Responsable:** compañero · **Fase:** 6 del [Plan Maestro](../docs/PLAN_MAESTRO.md)

## Primeros pasos
```bash
cd analysis-python
python -m venv venv
# Mac:      source venv/bin/activate
# Windows:  venv\Scripts\activate
pip install fastapi uvicorn pytest
```

> Nunca generar diagnósticos médicos. Solo "resultado orientativo".
